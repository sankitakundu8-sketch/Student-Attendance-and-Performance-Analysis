Student Attendance and Performance Analysis

Project Overview:
This SQL project analyzes student attendance, marks, and academic performance.

Objectives:
Calculate attendance percentages
Find students with low attendance
Calculate average marks by subject
Identify top-performing students
Check attendance eligibility.

Technologies Used:
SQL
MySQL

Dataset:
Contains 20 student records from BCA, BBA, and BCom departments.

Conclusion:
This project uses SQL queries to analyze student attendance and academic performance efficiently.
